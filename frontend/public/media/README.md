# Landing page media (placeholders)

All paths are referenced from `frontend/src/data/landing.ts`. Replace a file with one of the same name, or change the path there.

| Folder | Files | Used by | Suggested size |
|---|---|---|---|
| `events/` | `upcoming-1…6.jpg` | Upcoming events carousel | 800×1000 (4:5) |
| `past/` | `past-1…6.jpg` | Past events bento grid | 900×1100 |
| `gallery/` | `moment-1…12.jpg` | Gallery marquee and lightbox | 720×540 (4:3) |
| `merch/` | `tshirt.jpg`, `bag.jpg`, `bottle.jpg`, `stickers.jpg` | Merch posters and mobile cards | 640×800 (4:5) |
| `merch/` | `tshirt.mp4`, `bag.mp4`, `bottle.mp4`, `stickers.mp4` | Cursor-follow preview video (not shipped yet) | 640×800, muted loop, under ~1.5 MB |

The current photos are random placeholders from picsum.photos. Until a merch `.mp4` exists, the preview card shows the poster image with a slow zoom.
